# 风格基准：方法与陷阱

> **目的**：回答"skill 怎么知道自己生成的图有没有达到目标"。
> **工具**：`style_bench.py` ＋ `calibrate_provenance.py`
> **结论**：能做，但**四个测量陷阱**必须先趟平，否则数字会误导你改错地方。

---

## 一、能做什么

把"达到 Nature 级"这个无法验收的说法，拆成可量的指标：

| 指标 | 含义 |
|---|---|
| `whitespace` | 留白比例 |
| `color_richness` | 颜色丰富度 |
| `saturation` | 平均饱和度 |
| `gradient_ratio` | 渐变占比（区分插画 vs 扁平） |
| `edge_density` | 硬边密度（线条多不多） |
| `dark_ratio` | 暗像素占比（文字与描边量） |

用法：
```bash
# 建基准（扫 106 张期刊图，自动分成 T1/T2/T3）
python3 style_bench.py build refs_extracted/ -o style_baseline.json

# 1:1 对比（参考图 vs 复现图）—— 比跟类别基准比更准
python3 style_bench.py compare 参考图.png 我的图.png
```

副产品：自动把 106 张图分成 T1/T2/T3（找出 22 张 T3）。

## 二、四个测量陷阱（都是实测踩出来的）

### 陷阱 1：指标本身对出处敏感

**发现**：第一版报"颜色丰富度低 61%"，正要据此改图。先做校准——
把同一张图缩放和压缩，看指标怎么变：

| 指标 | 缩放 1.0→0.35 | JPEG q95→q40 |
|---|---|---|
| `color_richness` | 0.69 → **1.51** (+120%) | 0.69 → **1.34** (+95%) |
| `dark_ratio` | 稳定 | 稳定 |
| `edge_density` | 稳定 | 稳定 |

**结论**：`color_richness` 跨来源不可比（参考图是低分辨率切出来的，
天然有更多中间色）。已在 `METRIC_ROBUST` 里标记。

### 陷阱 2：在比不该比的东西

参考图 T3-05 **含 panel a 和 panel b**，我的复现只有 panel a。

| 指标 | 错误对比 | 裁到 panel a 后 |
|---|---|---|
| 留白 | +28% | **+4%** |
| 边密度 | −81% | **−28%** |
| 暗像素 | −94% | −72% |

**防呆**：`compare` 现在检测宽高比差 >15% 就警告。

### 陷阱 3：归一化不对称（最隐蔽）

`_load()` 里 `max_side=700`：参考图 608px **不降采样**，我的图 1280px **被降到 700**。
降采样本身模糊图像 → 压低边密度和暗像素 → **制造假的"你比参考少"**。

实测：`color_richness` 因此产生 **−21% 的假差距**（归一到同尺寸后只剩 −5%）。

**已修**：`compare` 现在先把两张图归一到同一像素尺寸再量。

### 陷阱 4：自己造的"管线模拟"是错的

为了验证"差距是不是出处造成的"，我把自己的图嵌进 PDF 再按同样 DPI 提取。
结果指标**被推得更远**而不是拉近——说明我造的管线不是参考图的真实出处。

**教训**：模拟出处很难做对。**更可靠的做法是归一化**（陷阱 3 的修法），
而不是模拟退化。

## 三、闭环验证：正确用法 vs 错误用法

**同样的指标、同样的目标，用法不同结果相反。**

### ❌ 错误用法：按指标整体调

"降饱和 + 加深描边"一起上：

| 指标 | 结果 |
|---|---|
| 饱和度 | +59% → −18% ✅ |
| 边密度 | −28% → +3% ✅ |
| 留白 | +4% → **−9%** ✗ |
| 渐变占比 | +2% → **−45%** ✗ |
| 视觉效果 | **更差**（把不该压暗的平面一起压暗了） |

**根因**：这些是**全局平均量**，分不清"该压暗的描边"和"该保持浅色的平面"。

### ✅ 正确用法：诊断 → 可视化 → 精确修 → 复测

1. `style_bench` 报 `dark_ratio` 差 −65%
2. **把暗像素掩码可视化** → 看到参考图的场线是**粗黑实心箭头**，
   我画成了细虚线
3. 只改那一处（场线改实心箭头 + 坐标轴加粗）
4. 复测：

| 指标 | 起点 | 修正后 |
|---|---|---|
| 颜色丰富度 | −21% | **−1%** ✅ |
| 渐变占比 | +2% | **+1%** ✅ |
| 留白 | +4% | **+3%** ✅ |
| 暗像素 | **−72%** | **−34%** |
| 边密度 | −28% | +14% |
| 饱和度 | +59% | +20% |

**6 项里 4 项进到 5% 以内**，且视觉确认确实更像参考图。

## 四、使用纪律（写进工具头部了）

> **这些指标是【诊断工具】，不是【优化目标】。**
>
> 它告诉你**往哪看**，不告诉你**调到多少**。
> 跳到"把所有指标都调到匹配" = 优化指标而不是优化图。

正确流程：

```
1. 量      → 发现问题
2. 判断    → 是配色问题还是别的？（人/模型判断，指标判断不了）
3. 可视化  → ★ 把指标对应的像素标出来，找到具体原因 ★
4. 精确修  → 只改那一处，别动全局
5. 复测    → 确认收敛，且别项没崩
6. 看图    → 确认视觉真的更好了
```

**第 3 步是关键。** 直接从指标跳到"调参数"必然伤及无辜。

## 五、能做到什么，做不到什么

| 能做 | 不能做 |
|---|---|
| ✅ 量化偏离（"饱和度比参考高 20%"） | ❌ 当达标判据（指标全绿 ≠ 图好） |
| ✅ 定位问题（"往配色看"） | ❌ 替代看图（最终判定必须人看） |
| ✅ 验证修正是否收敛、别项有没有崩 | ❌ 抓物理错误 |
| ✅ 自动分出图型（T1/T2/T3） | ❌ 抓审美 |

**一句话**：它提高下限、让偏离可见，**不替代人判**。

---

## 六、给老师汇报时怎么说

不要说：

> ~~"skill 能自动判断图有没有达到 Nature 级"~~

要说：

> **"skill 能把图与参考图做量化比对，指出偏离在哪、偏多少，
> 并验证修正是否收敛。但最终质量判定仍需人看图——
> 指标只能保证不偏离惯例，保证不了物理正确和审美。"**

后者更保守，但站得住，而且实测支持。
