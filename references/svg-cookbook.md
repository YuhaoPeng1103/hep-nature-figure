## 0. 这个文件解决什么问题

**问题**：matplotlib 画不了带光影的 3D 示意图。它的抽象层级是「数据→坐标轴→标记」，
没有材质、渐变、投影的概念。硬用它画示意图，结果是老师说的"花里胡哨且物理不准"。

**解法**：用 Python 拼 SVG 字符串。光影在 SVG 里是**确定性代码**：
`linearGradient` 做柱面明暗，`radialGradient` 做发光，`feGaussianBlur` 做柔光，
`opacity` 做半透明叠加。可复现、可 diff、矢量、可编辑。

**边界**：这是「示意图」方案，不是「数据图」方案。
- 有数据的图（谱、曲线、热图）→ 用 matplotlib，别用这个
- 无数据的图（碰撞几何、QGP 演化、探测器构型）→ 用这个

> ⚠️ **但真实期刊图经常把两者拼在同一张图里。**
> 例：T3-05（CME 综述 Fig.1）panel a 是 SVG 示意图，panel b 是 matplotlib
> 矢量场（quiver + 热图 + colorbar）。
> 这时**分工**：SVG 出 panel a，matplotlib 出 panel b，
> 最后用 matplotlib 的 `add_axes` / `subplot` 把 SVG 转成的 PDF 嵌进去拼版。
> 别试图用 SVG 画定量图，也别试图用 matplotlib 画光影示意图。

## 1. 工作流

```
1. 判定图型
   ├─ 有数据 + 坐标轴        → matplotlib（不走本手册）
   ├─ 3D 曲面（rainbow colormap）→ matplotlib plot_surface（不走本手册）
   └─ 无数据的立体/示意       → 本手册 ★

2. 拆元素清单
   把参考图拆成「物理元素」而不是「图形」：
   ✗ "一个橙色椭圆"          ✓ "QGP 火球（发光体，半径 r）"
   ✗ "一条红线"              ✓ "椭圆流方向箭头（从火球指向外）"
   这一步必须写下来，是后续所有工作的依据，也是「可复现」的地基。

3. 选图元（查 §3 速查表）

4. 拼装 → 渲染 → ★【迭代循环】★ → 自检（§6）→ 交付
        ↑                                │
        └──── 并排对比参考图，调参数 ─────┘
              （实战中要跑 3~5 轮）
```

**第 2 步是关键。** 跳过它直接画，就会变成"AI 随机画一张差不多好看的图"，
复现不了，Benchmark 过不了。

**第 4 步的迭代循环才是真正的工作量所在。** 第一次渲染几乎不可能对上，
必须用 `compare_ref.py` 和参考图并排看，逐项调参数，反复 3~5 轮。
把它当成流程的正常组成部分，而不是"没做好要返工"。

> 实战验证：复现 T3-03 时迭代了 4 轮（见 §8）。第一轮径向线全被盖住，
> 第二轮外壳过重，第三轮嵌套环太淡，第四轮才基本对上。

## 2. 环境与渲染

### 2.1 渲染必须用 cairosvg

```python
import cairosvg
cairosvg.svg2png(url="fig.svg", write_to="fig.png", output_width=2000)
cairosvg.svg2pdf(url="fig.svg", write_to="fig.pdf")   # 矢量交付
```

> ⚠️ **不要用 PyMuPDF 渲染 SVG**：MuPDF 的 SVG 渲染器不支持渐变，
> `url(#grad)` 全部渲染成纯黑，且不报错。详见 `SVG技术验证报告.md` 坑 1。

### 2.2 六个必须知道的坑（否则静默失败）

| # | 坑 | 规则 |
|---|---|---|
| 1 | PyMuPDF 不支持 SVG 渐变 | 用 cairosvg |
| 2 | cairosvg 不做字体回退 | `font-family` 只写**一个**存在且覆盖所需字符的字体 |
| 3 | 无字体兼有中文+Unicode下标 | 纯英文图用 `DejaVu Sans`；要中文才换 `SimHei` |
| 4 | `baseline-shift` 被忽略 | 下标用 `dy` |
| 5 | 百分比 `font-size` 解析错误 | tspan 内用**绝对字号** |
| 6 | `text-anchor="middle"` + tspan 算错锚点 | 居中标签用 Unicode 下标字符，别用 tspan |

**这些坑的共同特征：不报错，只是画错。** 所以 §6 的自检清单不是可选项。

### 2.2b 第七个坑 —— 绘制顺序就是 z 序（实战第一大坑）

**SVG 没有 3D 深度，也没有真正的透明混合。后画的永远盖住先画的。**

实战复现 T3-03 时，第一版把径向线画在棱柱前表面**之前**，
结果整组线被不透明前表面完全盖住——**图看起来"少了元素"，但不报任何错**。

规则：
```
画序 = 从后往前
  背景 → 外轮廓/后壳 → 前表面 → 表面上的线/网格 → 前景物体(发光体/标注)
```

**推断方法**：拿到参考图，问自己"如果这是一叠纸，从下到上依次是哪几层？"
把这个顺序写进元素清单（E1→E8 就是画序）。

### 2.3 字体选择

```python
FONT_LATIN = "DejaVu Sans"   # 含 ε η φ 和 ₁₂₃ —— 期刊图（英文）默认用这个
FONT_CJK   = "SimHei"        # 含中文字形 —— 只有需要中文标注时才用
```

## 3. 图元速查表

全部在 `svg_lib.py` 里。`s = SVG(w, h)` 创建画布，方法可链式调用。

### 材质（返回渐变 id，自动注册到 defs）

| 方法 | 用途 |
|---|---|
| `s.mat_cylinder(base)` | 圆柱侧面：横向明暗 |
| `s.mat_sphere(base)` | 球体：高光偏左上 |
| `s.mat_fireball()` | 火球：白热→橙→红，边缘透明 |
| `s.mat_glow(color)` | 外辉光 |
| `s.mat_medium(color, a)` | 半透明介质 |
| `s.blur(std)` / `s.shadow(...)` | 高斯模糊 / 投影滤镜 |

### 物理元素

| 方法 | 对应物理对象 | 关键参数 |
|---|---|---|
| `s.fireball(cx, cy, r, glow)` | QGP 火球（发光体） | `glow` 控制外晕倍数 |
| `s.cylinder(cx, cy, w, h, squash, amp, waves)` | 纵向剖面圆柱 | `squash` 决定 3D 感（★关键）；`amp/waves` 做波形起伏 |
| `s.nucleus(cx, cy, r, n, seed)` | 原子核 / 核碎片 | `seed` 固定保证可复现 |
| `s.ellipsoid(cx, cy, rx, ry, base, a)` | 半透明介质 / 火球外壳 | `dash` 做虚线轮廓 |
| `s.ring3d(cx, cy, R, r, tilt)` | 环形探测器 | `tilt` 是透视压缩比 |
| `s.sphere(cx, cy, r, base)` | 通用受光球 | |
| `s.perspective_grid(cx, cy, rx, ry)` | 反应平面 / 探测面网格 | |
| `s.axes3d(ox, oy, sx, sy, sz)` | 3D 坐标轴 | 与 `project()` 投影一致 |
| `s.arrow(x1,y1,x2,y2, curve)` | flow 箭头 / 演化箭头 | `curve=0` 直线，>0 上弯 |
| `s.track(x1,y1,x2,y2, bend)` | 粒子径迹 | |
| `s.text / s.title` | 标注 | `title(..., cjk=True)` 走中文字体 |

### 通用几何（由 B2 复现补充）

| 方法 | 对应物理对象 |
|---|---|
| `s.polygon(pts, ...)` | 倾斜平面 / 透视平行四边形（反应平面、探测面） |
| `s.shell(cx, cy, rx, ry, angle)` | 半透明碗/壳形（畴结构、介壳、区域边界） |
| `s.blob(cx, cy, w, h)` | 有机形状团块（火球、熔融区） |
| `s.badge(cx, cy, r, label)` | 带符号圆徽章（电荷 +/−、序号） |
| `s.dashed(pts, ...)` | 折线虚线（场线、辅助线） |
| `s.axes_alternate(...)` | 另一套 3D 坐标约定（y↑ / x→ / z↙） |

> ⚠️ 存在**两套 3D 坐标约定**，别混用：
> `axes3d` 是 y↗ / x→ / z↑；`axes_alternate` 是 y↑ / x→ / z↙。
> 参考图用哪套就跟着用哪套。

### 3D 投影约定

`axes3d` 与 `perspective_grid` 用的是同一套**斜投影**：
**x 向右、y 向后上、z 向上**。要手写 3D 点用这个：

```python
def project(ox, oy, x, y, z, sx=70, sy=30, sz=90):
    """斜投影。与 axes3d 一致。"""
    return ox + x * sx + y * sy * 0.7, oy - y * sy - z * sz
```

## 4. 技法配方（按效果查）

### 想要「圆柱有立体感」
`squash ≈ 0.18` 的椭圆端面 + `mat_cylinder` 横向渐变 + 一条模糊白高光。
**椭圆端面是 3D 感的关键**——没有它，渐变再好也是平面。

### 想要「发光体」
三层叠加，顺序不能错：
1. 外晕：大圆 + `mat_glow` + `blur(r*0.16)`
2. 本体：`mat_fireball` 径向渐变
3. 内核高光：偏心小椭圆，`opacity 0.78` + 模糊

### 想要「半透明介质」
`ellipsoid` 用 `mat_medium`，透明度 0.35–0.55。
**先画介质，再画内部物体**——SVG 没有真透明混合的 z 序，靠绘制顺序。

### 想要「曲面/曲面带」
逐格填色 + 画家算法（远的先画）：
```python
quads.sort(key=lambda q: q.z)   # z 是深度
```
色相用 HSV 从蓝(0.66)到红(0.0)，亮度随高度升 → 有受光错觉。

### 想要「透视网格平面」
横向画一族扁椭圆弧（沿 y 等分），纵向画从中心辐射的线。
见 `perspective_grid()`。

## 6. 交付前自检清单

**每一条都要给出证据，不能只说"已检查"。**

### 自动化工具（别手工查，会漏）

```bash
# 渲染静默失败检测：空白/渐变失效/色彩贫乏/元素命中
python3 check_render.py fig.png --probe 0.5,0.10 --probe 0.26,0.30

# 与参考图并排对比（迭代时每轮都跑）
python3 compare_ref.py 参考图.png fig.png -o compare.png
```

`check_render.py` 用**归一化坐标**（0–1）指定元素采样点，与渲染尺寸无关。
它的四项检查直接对应上面的坑：

| 检查 | 抓什么 |
|---|---|
| 非空白 | 渲染完全失败 |
| 无黑块 | **用了不支持渐变的渲染器**（PyMuPDF 会 36% 纯黑） |
| 色彩丰富度 | 渐变被压成色块 |
| 元素命中 | **字体丢失 / z 序错误导致的局部空白** |

> 采样点必须覆盖**每个关键元素**——尤其是文字标注的位置。
> 中文丢失不会报错，只有采样才发现得了。

### 机器可判（AI 自己核对并报告）

- ☐ **渲染无静默失败**：PNG 里预期的每个元素位置都有非白像素
      （防字体丢失——中文丢了不会报错）
- ☐ **渐变生效**：抽查渐变区域中心像素不是纯黑
      （防用了错误渲染器）
- ☐ **文字完整**：所有标注字符都渲染出来了，没有豆腐块 □
- ☐ **元素清单对齐**：第 2 步写的元素清单，逐个对照成图，无遗漏无多余
- ☐ **物理量正确**：坐标轴标签、单位、符号（ε₂/β₂/γ 等）与参考图一致
- ☐ **无编造**：没有凭空添加参考图里不存在的元素或数值
- ☐ **矢量交付**：导出 PDF/SVG，文字可选中（不是被转成轮廓）

### 人工判

- ☐ 物理表达准确（这一条机器判不了，必须人看）
- ☐ 视觉达到可投稿水平
- ☐ 与参考图的结构/物理内容一致（老师 Benchmark 的验收标准）

## 7. 禁止事项

1. **禁止用 GPT Image / DALL·E 替代精确复现。**
   它出的是位图、不可复现、结构不可控。可以用于"概念草图/灵感"，但不能冒充
   Benchmark 要求的复现输出。
2. **禁止在渲染失败时降级糊弄。**
   装不上 cairosvg 就报告阻塞，不要改用别的方式糊一张"差不多"的图。
3. **禁止跳过元素清单直接画。**
   跳过就变成"AI 随机画"，复现不了。
4. **禁止用 Unicode 下标 + 中文字体的组合。**
   会静默丢字符（坑 3）。
5. **禁止在一张图里混用多套投影约定。**
   `axes3d` 的 x/y/z 方向和手写 `project()` 必须一致，否则透视会崩。

## 10. 复合图拼版（示意 + 定量混排）

**这是 T3-05 暴露的大类**：真实期刊图经常把 SVG 示意图和 matplotlib 定量图
拼在同一张图里。老师自己的 Jia Fig.1 也是复合图（示意图 + 3D 曲面）。

### 分工原则

```
panel a  无数据示意图  →  svg_lib 出 SVG  →  cairosvg 转 PDF
panel b  有数据定量图  →  matplotlib 直出 PDF
        ↓
   拼版层统一组装  →  单张矢量 PDF
```

**不要**用 SVG 画定量图，**也不要**用 matplotlib 画光影示意图。
各做各的，在拼版层汇合。

### 拼版工具

```bash
python3 assemble_panels.py -o fig1.pdf --page 180x95mm \
    --grid 1x2 --ratios 1.05,1 --labels a,b \
    --panel panel_a.pdf --panel panel_b.pdf
```

已用 PyMuPDF 的 `show_pdf_page` 把各面板作为**矢量 XObject** 嵌入，
保矢量、保文字可选（实测文字可完整提取，105 KB / 180×95 mm）。

> ⚠️ **面板标号属于拼版层，不要画在面板内部**，否则会重复。
> 用 `--labels a,b` 统一加。

### 关键纪律：定量面板的物理诚实性

panel b 那类图**必须来自真实数据或真实计算**。
复现 T3-05 时我给 panel b 用的场是**唯象构造**（流函数拼出来的双涡旋），
**不是** QGP 磁场的第一性原理计算——所以我在脚本头部写明了声明。

**规则**：拼版图里凡是标了物理量的面板（坐标轴带单位、colorbar 带量纲），
其数值必须有来源，不能为了"看着像"而编。示意图可以艺术化，定量图不行。
