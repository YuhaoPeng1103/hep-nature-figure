# 否决权分层：硬物理 / 画法 / 美观

> 作者 2026-10-11：「虽然 IR 是物理正确的东西，用来检查生图模型的物理正确性，
> 但有时候也会有不美观的地方，那我该怎么办呢……其实 IR 里的那个杏仁状的 QGP 就很难看。」

## 为什么定这条

IR 里常把**不美观的画法**和**物理**写在同一句 `physics_role` 里，于是写 IR 的人
可以把自己的**口味升级成"物理要求"**，而闸门一条也拦不住：

- `ref_guard.py` 的 `ir_contract()` 只查 `style.mode == render3d`、有没有 3D 材质语言、坐标约定声明了没有；
- `ir_layout_guard.py` 只查版式有没有被写死。

**实测代价（不是假设）**：A 档（作者认可的那一脉，T3-30 复刻）到 C 档，为了满足
`style.conventions` 里那句「全图唯一一个三维场景、没有插图框」，把作者参考图里
`−b/2` / `b/2` 的碰撞几何插图**整块删掉了**，还顺手把质子红/中子灰的核子配色改成纯灰。
**那不是模型画错，是 IR 越权。**

## 三层

### 第 1 层 · 硬物理（唯一有否决权）
判据只有一条：**能不能在图上量出来 / 证伪。**

- `b` 的两条见证线各落在一个核芯上；
- 沿 b 的两支推力箭头 : 垂直于 b 的两支 > 1.5；
- `v2` 标在发射最密的那一侧；
- 同一轴名只对应一根轴杆，三轴一一对应。

写进 IR 的 `hard_physics:`，**每条必须给 `measure`（怎么量）**。
**给不出 measure 的，说明它不是物理，是画法。**

### 第 2 层 · 画法偏好（降级为建议）
判据：不涉及任何可以在图上量出来的关系。

- 「单幅、不要插图框、不要分割线」；
- 「三轴画成画面空白角上的一组紧凑小图标」；
- 「火球画成光滑、对称、躺在板面内的杏仁」。

写进 IR 的 `style_preferences:`。**可被更美观的画法替换** —— 替换后只要第 1 层不破就行。

### 第 3 层 · 美观 / 质感（生图模型最擅长）
材质、光照、体积感、配色、粒子航迹疏密 —— **交给模型，别去规定**。

## 三条操作规则

1. **「以生图模型的图为准」有前提** —— 只在它不违反第 1 层时才以它为准。生图模型在
   "关系"上经常打架（同一个 `x` 标到两根不同的杆上、`b` 不落在核芯上、面内箭头比面外短），
   这些必须改，不能"以它为准"。
2. **「能更美观就增加」有边界** —— 增加的只能是第 2 层的视觉元素，**不许顺手删骨架**。
3. **默认是"不变"，改动要举证** —— 新画法要在第 1 层上不更差、且观感更好。
   这与工作区 AGENTS.md「草图里符合物理的不许删」是同一条。

## 写进 IR 的样子

```yaml
hard_physics:                     # 第 1 层：唯一有否决权
  - id: HP1
    claim: b 的双头尺寸箭头两条见证线各落在一个核芯的深色小点上
    measure: 见证线端点 <-> 核芯点 的像素距离 < 5% 核直径
  - id: HP2
    claim: 沿 b 的两支推力箭头比垂直于 b 的两支至少长 1.5 倍
    measure: 两组箭头的像素长度比 > 1.5
  - id: HP3
    claim: x / y / z 各只出现一次，同一轴名的两次标注在同一根轴杆两端
    measure: 字形识别出的轴名计数 + 轴杆端距 < 0.1 画布宽

style_preferences:                # 第 2 层：只是建议，可被更美观的画法替换
  - 单幅、不要插图框、不要分割线
  - 三轴画成画面空白角上的一组紧凑小图标
  - 火球画成光滑、对称、躺在板面内的杏仁
```

## 机械闸门

| 闸门 | 查什么 |
|---|---|
| `ref_guard.py --ir <IR>` | `NO_HARD_PHYSICS` 缺硬物理层（硬伤）、`HP_NO_MEASURE` 没给 measure = 不是物理（硬伤）、`NO_STYLE_PREFS` 没写画法层（软警） |
| `render_brief_gate.py <brief> --ir <IR>` | `R7` 位图简报「必须改对」块里每条必须带 `[HPn]` 出处；追溯不到的改动 = 凭口味改，不许写。`R8` 不许引用 IR 里没有的 id |
| `ir_to_genbrief.py` | 硬物理层带 `[HPn]` 编号顶到简报最前；画法层改成「外观建议（可以改得更漂亮）」 |

★ R7 只在 IR 确实声明了 `hard_physics` 时启用 —— 老简报不受影响。

## 两条阶梯纪律（作者 2026-10-14；闸门 `ladder_gate.py` 的 `L11` / `L12`）

这两条都是把第 1 层（物理）/ 第 3 层（观感）分开之后自然落下来的 —— 阶梯里的每一轮改动，
都要分清「改的是物理还是观感」。作者原话：「对 C 档修改物理几何的地方不修改材质……
我建议说『不要修改材质』」「B 保留 A 好看的元素，比如如果 A 画的核子好看就保留核子，
甚至可以在此基础上更美观」。

### `L11` · C 档改「形状 / 几何」≠ 改「材质 / 质感」

- **形状 / 几何是物理**：UPC 的洛伦兹收缩（圆球 → 沿束流压扁的高瘦扁球）必须改对。
- **材质 / 质感是观感**（第 3 层）：光滑深蓝球面 vs 粗糙石块，**不该在改形状时顺手换掉**。
- 闸门：C 档增量块命中形状 / 几何类词时，简报必须写明**材质保持不变**，否则硬伤。
- ★ **写法是「材质保持不变（以给的那张图 —— 上一版的材质为准）」，不要替模型指定材质**
  （作者 2026-10-14：「不要写材质保持光滑啊，应该是材质保持不变」）；点名具体材质
  （光滑 / 粗糙 / 哑光…）只出软警。
- 实测代价：C 档只让把圆球压成扁球，模型把上一版的光滑球面一起重画成了粗糙石块
  （`keep_gate` 质感漂移 **0.881**）；补一句「材质保持不变」并把上一版（B）当 `--content-ref`
  之后（C3），漂移降到 **0.485**、删除 0 处。

### `L12` · B 档要继承 A 的视觉优点

- A 档是**诊断档**，但它常常**画对了东西**（比如核子的样子、布局、配色）—— 这些在 B 档
  **要留着**，只在此基础上做得更好看，**不许推倒重画**。
- 闸门：B 档简报必须写明「保留上一档画得好的元素，可在其基础上更美观」，缺这句 = 硬伤。
- 与 `L10` 不冲突：`L10` 只判 **C 档**的「严格…不许变」措辞；B 档不判严格措辞，但判这条「继承优点」。

两句都是**简报的固定项** —— `brief_lite.py` 编译时自动带上（C 档自动加 ①、B/C 档自动加 ②）。
