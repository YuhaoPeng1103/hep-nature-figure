# 用纯代码重绘复杂连续渐变 SVG

给定成品参考图，同时要连续渐变、对象级编辑和遮挡补全时，按 [直接重绘](direct-svg-redraw.md) 开始。以参考图校准轮廓、锚点、色带和光照，交付逐图绘制源码与两版 SVG。要求低像素差时，先定位哪一部分失配，再修改对应几何或材质。把参考像素逐格转成平涂路径会在放大时露出色块。

## 先做完整对象

1. **量轮廓和锚点。** 按面板记录坐标、边界、色带转折、光源和相互遮挡关系，然后建共享对象表。有解析曲面时从参数和投影出发。只有参考图时，用测到的锚点构造可编辑 Bézier 或参数几何，注明形体与数据的近似。
2. **在代码中画完整形体。** 网格贯穿前景覆盖区。环面前后壁、粒子簇前后层、光晕和射线分别建组。为需要独立操作的子组也写唯一的 `id` 和 `data-element`。用 SVG 叠放表达遮挡。参考图上的遮挡掩膜可用于排除拟合样本，绘制时完整对象仍保持自己的边界。
3. **先拟合大色场，再加细节。** 给实体一个低频的 `linearGradient` 或 `radialGradient`。涡旋、体积烟雾和光晕可叠圆形或沿纹理方向转动的椭圆径向渐变，外端 alpha 衰减到零。以光照、走向和局部残差选择控制点。再用少量 Bézier 丝带、网格和高光还原细节。把柔边渐变作为连续基函数拟合，可从大尺度逐步加到小尺度。避免用单色小格盖满轮廓。
4. **保持前景独立。** 光晕、射线与烟雾使用自己的颜色和透明度。参考图是合成色时，按 [双版流程](dual-svg.md) 估计前景颜色和 alpha，或以材质模型直接绘制。试移动前景应露出自然延伸的底层光影。可据形体合理补全隐藏区，并标注它是重建。

## 让复杂剪裁稳定回渲染

对象自己的 `clipPath` 是常用方法。大量半透明渐变叠在复杂剪裁里时，在交付软件与另一种渲染器各抽查一个关键局部。某个渲染器出现硬边矩形或漏绘时，先排查结构和剪裁，再修色场。

如果问题来自剪裁，可在生成 SVG 时求 **渐变形体与自身轮廓的几何交集**。仅对跨过边界的光斑求交。把交集输出为原生路径，保留原渐变的坐标、焦点、变换及透明色标。渐变可用 `gradientUnits="userSpaceOnUse"` 锁定在该对象的坐标系里，避免切出新路径后用新包围盒重算梯度。让轮廓与拟合参数留在同一份源码中，改形后可重建交集。已有交付版若有渲染器差异，记录使用的软件和受影响细节。

## 在原尺寸和放大图上验收

- **原尺寸看位置与色差。** 保持同一画布、坐标原点和背景，回渲染到参考图像素尺寸。留白较多时同时记录整图、各面板及前景 MAE，优先修偏差明显的局部。
- **放大看连续性。** 从 SVG 重新渲染关键局部，通常约 3–4 倍。查矩形硬边、条带台阶、接缝、剪裁漏绘和光晕是否带上旧背景。用同一对象的原尺寸回渲染判断整体光影。
- **真编辑看对象完整性。** 只改一个或多个已声明组的 `transform` 或 `display`，按 [双版流程](dual-svg.md) 检查两份文件并回渲染。记录露出的几何、移动前后的对象材质和残影。RGBA 渲染读数用于量化抗锯齿等差异。严格零差与结构通过分别记录。
- **交付可复现结果。** 两版 SVG、绘制源码、对照图、回渲染 PNG、一次实际试编辑和已知偏差。正式投稿按既有流程查 PDF。

下面的命令生成并排图和原尺寸 JSON。`--region` 可重复。坐标从左上角起算，右下端点不含在区域内，按实际面板范围替换。

```bash
python scripts/compare_ref.py reference.png figure_texture.png -o comparison.png \
  --metrics fidelity.json --region surface 21 16 619 485 --region collision 1091 108 1655 414
```

度量时透明图合成在白底上，前景取两图中任一图最小 RGB 通道值小于 235 的像素并集。这个白底诊断会计入漏画及多画区域。报告同时给出前景像素数，完全空白区域的前景误差记为 `null`。两图像素一致时 PSNR 为无穷大，JSON 用 `null` 表示。非白底图可用明确的局部区域或任务指定的掩膜度量。

一次六面板验证中，细纹理版整幅 RGB MAE 为 5.98/255，对撞面板为 19.73/255。放大与显隐试验确认渐变连续且前后对象完整，局部误差指出粒子位置与射线仍可改善。整幅 MAE 适合比较同范围的迭代，无法单独判断渐变外观或编辑后的几何。
