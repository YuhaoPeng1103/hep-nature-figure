# 位图转 SVG 的像素保真门禁

## 适用范围

已有目标位图要求转 SVG，以及由作者选定成品位图再转 SVG，走下方的双版交付审查。风格图只用于外观目标，从 spec 直接创作时以 spec 和视觉回执验收。若作者要求修正参考图的硬物理，先记录改动并请作者确认修正后的比较基准。

绘制前固定目标位图和区域表。坐标为原图像素，左上为原点，右下端点不含。区域应紧贴所有关键物理对象和标签，包括画布边缘的核团、下栏和色标。重叠对象可使用重叠区域。参考图和区域表在返修间沿用。

```bash
python scripts/fidelity_gate.py --reference input.png \
  --edit out/figure_edit.svg --texture out/figure_texture.svg \
  --region left_nucleus 0 148 177 565 \
  --region plasma 211 13 1285 655 \
  --region main_jet 479 151 1515 491 \
  --region right_nucleus 1519 150 1672 537 \
  --region evolution 88 653 1427 887 \
  --region density_scale 1482 531 1635 844 \
  --outdir out/fidelity
```

按实际尺寸替换示例区域。作者指定只交一版时提供对应参数。闸门读取 SVG 本身，用 CairoSVG 以原图尺寸回渲染。参考与回渲染的透明部分都合成到白底。固定画布坐标，保持纵横比，无自动配准、裁边或缩图。`fidelity.json` 记录 SVG 和参考图 SHA-256、渲染器版本、盒子、阈值和读数。同目录保存回渲染、并排和固定量程的热图。工作区规定的生产 PNG 仍另行等比导出。

## 双版交付审查

区域表同时包含大物体和对成图关键的细结构。轴杆、箭头尖和边缘、线圈、球缘或字形分别取紧贴的区域，不用覆盖整个面板的大框代替。给这些有可辨轮廓的框加 `--structure`。柔和光晕、烟雾、渐变色块可继续用一般色差区域。

```bash
python scripts/review_redraw.py --reference input.png \
  --edit out/figure_edit.svg --texture out/figure_texture.svg --source draw.py \
  --region plume 220 110 710 490 --region jet_tip 720 86 920 190 \
  --region axes 50 384 147 520 --structure jet_tip --structure axes \
  --move escaping-jet -32 24 --outdir out/review
```

区域和组名按本图填写，区域是原图像素，位移是 SVG 用户坐标。选择一个会露出其他几何的前景组；两版都会实测移动和隐藏。可用 `--zoom ID` 选最有代表性的局部，默认输出结构框的 4 倍图。`review.json` 绑定参考图、两版和绘制源码哈希，收录原尺寸色差和结构结果、4 倍对照、双版结构、移动和显隐图。查看这些图后再交付。机器失败时交付说明写明待返修处，复测同一位图、同一区域和实际要交的 SVG。

结构检查在 RGB 渠道平滑后提取边缘。在原尺寸上双向找邻近边缘，参考边缘中找得到的比例为召回率，成图边缘中有参考配对的比例为精确率，两项均须达到 75%。容差是长边每 1024 px 约 3 px，最少 1 px。整图边缘得分仅作读数，关键结构按各自裁框验收。若框内参考边缘太少，重新量有可辨边缘的小区域。边缘图红色为参考中缺失的边缘，蓝色为成图多出的边缘。这个检查用于结构对齐，光照、文字、补绘和轮廓连续性仍需看 4 倍与试编辑图。

单版和迭代诊断可直接运行 `fidelity_gate.py`，以 `--structure ID` 复用同一结构度量。双版最终结果统一走上面的入口。

## v5.2 默认预算

每个像素误差为 RGB 三个通道绝对差的均值，取值 0–255。MAE 为这些像素误差的平均值。`>32` 一列以百分比记录像素误差超过 32 的比例。PSNR 为全图 RGB 附加读数。覆盖全画布的 8×8 网格包含最右及最下边缘，可捕捉区域表遗漏的局部损失。表中是 v5.2 的初始默认预算。

| 范围 | 几何版 MAE / >32 像素比例上限 | 纹理版 MAE / >32 像素比例上限 |
|---|---:|---:|
| 全图 | 12 / 12% | 8 / 8% |
| 每个已登记区域 | 20 / 24% | 14 / 16% |
| 每个网格 | 30 / 40% | 22 / 32% |

同一版本的全部检查均通过才返回 0。超限返回 1，输入或渲染失败返回 2。仅有并排图、总体 MAE 或风格门禁通过时，继续运行本门禁。若 SVG 有渲染器差异，另外在目标软件复核关键区域并记录；发布验收仍需确认闸门使用的回渲染。

## 有超限时怎么修

1. 读失败区域和对应热图。将形体错位、漏件、文字差异、色场残差分开定位到实际对象。
2. 轮廓错位先修锚点和路径。有颜色和光照偏差时，用对象内连续渐变、沿高光走向的透明色场、柔边光斑或曲线光丝拟合可见像素。复杂对象可沿用 [透明纹理流程](dual-svg.md) 先补底，再分离前景颜色与 alpha。优先修局部误差最大的对象，例如两个核团分别对齐核子轮廓、色温及高光。
3. 保持 SVG 纯矢量、原生文字与命名组。通过显隐和平移核对遮挡补全和独立透明纹理。最终位置重新回渲染，复测同一原图和同一区域。
4. 仍超预算的版本作为待返修稿，报告实测值和剩余偏差。仅在作者明确改为允许视觉近似的改绘任务时，按新任务描述交付。

## 回归样本

喷注演化图的旧交付通过了结构、3D 和风格检查。纹理版相对 1672×941 原图的全图 MAE 为 20.65/255，两侧核团超过 50/255。v5.2 用原图和最终 SVG 重跑，两版均应返回 1，并指出核团超预算。通用回归另外验证一致回渲染通过，以及整图误差很低但右下角对象丢失时拒绝。
