═══ 一、物理内容（这是图要表达的东西，不许改）═══
高能重离子碰撞里，硬散射在极早期（火球还在形成时）就产生一对**背对背的部分子** （dijet）。这一对部分子随后必须**穿过介质**才能逃逸。夸克-胶子等离子体对 **带色荷的**部分子是强相互作用的介质：穿过的部分子会通过**胶子轫致辐射** （gluon bremsstrahlung）把能量不断沉积给介质 —— 这就是**喷注淬火**。 结果是不对称：**穿过介质路径长**的那一侧喷注被压低（能量少、高 pT 强子少、 末态喷注偏软），**路径短**的那一侧几乎不受影响。 物理意义：这就是"双喷注不对称"（dijet asymmetry）与核修正因子 R_AA < 1 的微观图像，也是 QGP 存在的最直接证据之一。 注意：能量损失正比于**穿过介质的路径长度**，所以"一侧长、一侧短"是这张图的 关键信息 —— 不是"一侧被挡住"。 视角：**斜视 3D** —— 介质画成有体积的椭球团块（束流方向竖直）， 两个喷注在横向平面内背对背飞出，用锥形+强子团表现末态。

图中要出现的**物理对象**（数量要对，但不能把实现细节当内容）：
  · QGP 介质 —— 碰撞产生的夸克-胶子等离子体。束流方向竖直 → 介质在图上**竖直拉长** （不是圆球）。它是**半透明**的：要能看见里面的喷注轨迹、顶点与胶子辐射。【形态：竖直拉长的椭球（半透明）+ 边界羽化】【材质：**半透明发光体**：橙→红的球面明暗（3D 体积感），中心偏亮点略偏左上； 靠近轮廓再压暗一档（limb darkening）让边缘"转过去"；最外层橙红日冕边缘 羽化散开。整体透明度约 55%~70% —— 里面的喷注、顶点、辐射点必须**看得清**。 ★ 表面只在**大尺度**上有结构（层壳厚度、日冕羽化、3~5 条又宽又柔的弯曲 丝状亮带）；**禁止**细密颗粒/噪点/抖动纹理（矢量化时会变成脏块）。】
  · 硬散射顶点 —— 一对背对背部分子的产生点。它必须在**介质内部**（硬散射发生在火球形成早期）， 而且必须**明显偏介质右侧**（cx≈0.60，cy≈0.45）： ★ 顶点偏哪边，哪一边的出射路径就短。能量损失 ∝ 穿过介质的路径长度， 所以"顶点靠右"才是"朝右下的短、朝左下的长"的唯一画法。 （旧版把顶点放在偏左下，算出来两条弦长刚好是反的：朝左下 0.09 画布宽就出射、 朝右上反而 0.30 —— 3/3 草图都照抄了这个反的几何，见 CHANGELOG v2.7.2。）【形态：小而亮的爆发星芒（几根短刺 + 亮核）】【材质：亮黄白爆发（#fffdf0 → #ffe27a），尺寸小（半径约画布高的 3%），不要大光斑】
  · 束流方向 —— 介质沿**束流方向**拉长 —— 用一个竖直的双向箭头标出来。【形态：竖直双向箭头（很短、细），画在**介质右侧偏下**的空隙处 （x≈0.72、y 0.57~0.79；那里在蓝喷注下方、介质轮廓外，别压到任何对象）；dir=竖直】【材质：深灰 #2a2d33，细（arrow 线宽），不要与喷注混淆】
  · 未淬火喷注 —— 背对背两个喷注里**穿过介质路径短**的那一个（朝右上）—— 顶点本来就在介质右侧，所以它**在介质内只有很短的一段（≈0.04 画布宽）就出射**， 大部分锥体画在介质外面。介质压制很小，末态是**准直、高 pT 强子多**的完整喷注。【形态：从顶点出发的**准直锥**（越远越宽一点点），顶端一簇小圆球（强子）；from=[0.6, 0.45], to=[0.88, 0.3]】【材质：深蓝色实心锥（#2f6fd0 → #1b3f8f，带球面明暗与描边），顶端 6~9 个浅蓝白小球 （#dce8ff）成簇。整体**明亮、干净、准直**。】
  · 被淬火喷注 —— 背对背的另一个喷注，朝左下、**穿过介质的路径长** —— 因为顶点在介质右侧， 它要**几乎横穿整个介质（≈0.25 画布宽）**才出射，沿途通过胶子轫致辐射 不断损失能量，出介质后变软、变暗、高 pT 强子明显减少。 ★ 它与 J1 **严格背对背**（在图上近似 180°）。 ★ 两条弦长之比必须 ≥1.8（长/短），这一条由闸口的机器检查量（不是靠看）。【形态：同 J1 的锥，但在介质内一段**逐渐变暗、变宽、颜色偏灰**；from=[0.6, 0.45], to=[0.15, 0.65]】【材质：锥体从深蓝**渐变为灰蓝→浅灰**（#2f6fd0 → #8fa0bb → #c9d2de）， 轮廓比 J1 模糊一档；顶端强子**只有 2~3 个小球且更暗**（#aab6c8）。 与 J1 并排看必须一眼看出"这一侧被压低了"。】
  · 胶子轫致辐射 —— 部分子在介质内辐射胶子 —— 这是能量损失的**机制**，必须画出来。 辐射点只出现在**介质内部**、沿着 J2 的轨迹。【形态：4~7 个黄绿色小光点 + 短短的螺旋/波纹线，越靠近介质边缘越少越小；along=J2, region=介质内部】【材质：亮黄绿 #ffe27a / #b6e33a，尺寸很小（半径约画布高的 0.8%），不要连成光带】
  · 顶点标签 —— 标注硬散射顶点【形态：text=hard scattering】
  · 介质标签 —— 标注 QGP 介质【形态：text=QGP medium】
  · 未淬火喷注标签 —— 标注短路径、未被压制的一侧【形态：text=unquenched jet (short path)】

═══ 三、★ 几何约束（画错这张图就是废图）═══
**图像模型不知道物理，这一节是最容易画错的地方。**
★ 矢量那一步必须拿这一节**逐条对账**。
  · 位图已经过了闸口（check_sketch 答完所有几何问题）→ **就该照它画**；
  · 对不上 = 位图错了 → 回去改简报重出，而不是在矢量那步偷偷「修正」。

  · 两个喷注严格背对背：两条锥轴之间的夹角  要求 180° ± 15°   ← **为什么**：双喷注来自同一个硬散射顶点，动量守恒 → 背对背。
  · 硬散射顶点在介质内部且偏右：顶点的像素位置是否落在介质椭球内、且在椭球中心的右侧  要求 成立（内部 cx≈0.60 明显偏右，不贴边、不在椭球外）   ← **为什么**：这张图讲的正是"部分子要穿过介质才能逃逸"。
  · 两侧介质路径长度不同且"左下长、右上短"：沿两条喷注轴，落在介质掩膜内的弦长（★ 闸口已实现机器自动量，见 机器 段）  要求 J2 的弦长 > J1 弦长的 1.8 倍   ← **为什么**：能量损失 ∝ 路径长度；两侧一样长就讲不出"不对称"。
  · 被淬火一侧明显更弱：两侧喷注锥的平均亮度/饱和度；顶端强子小球个数  要求 J1 更亮更饱和、强子 ≥6 个；J2 更暗更灰、强子 ≤3 个   ← **为什么**：这是图要传达的唯一结论。
  · 胶子辐射只在介质内、只沿长路径一侧：黄绿光点是否落在介质椭球内且靠近 J2 轴  要求 全部落在介质内；J1 一侧没有   ← **为什么**：能量损失发生在介质里。
  · 介质是竖直拉长的椭球：介质掩膜的 高/宽 比  要求 ≥ 1.6   ← **为什么**：介质沿束流方向（竖直）拉长。

═══ 五、明确禁止 ═══

3. **不要改视角或投影**。IR 里写了视角约定就照办；换视角会让几何约束全部失效。
4. **不要画成照片级**。**允许** 3D 渲染的立体感（球面明暗 / 高光 / 柔和阴影 / 平滑渐变 / 表面网格线）—— 这些矢量化后是真 `<gradient>`，是加分项；但**不要**照片级材质纹理、胶片颗粒/噪点纹理、景深虚化、镜头光晕。（示意性的细小符号——组元点、场线、网格线——不算「颗粒噪点」，该画就画。）
5. **不要加渐变背景、装饰性光斑**这些摄影感的东西（背景保持纯白）。
