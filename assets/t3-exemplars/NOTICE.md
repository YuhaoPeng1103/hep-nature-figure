## 三、判定方法（自己建库时照这个来）

1. **`arXiv` 的 API 字段不可依赖**：本批几十篇的 `arxiv:license` **全部返回空**，
   连已确认 CC BY 4.0 的 `2405.08749` 也返回空。必须抓 abs 页：

   ```bash
   curl -sS -A "Mozilla/5.0" https://arxiv.org/abs/<id> \
     | grep -o 'creativecommons.org/licenses/[a-z-]*/[0-9.]*'
   ```

2. **PDF 正文同样不可靠**：59 篇里只有 1 篇（`1809.09693`）正文印了 CC 声明，其余一个字都没有。
3. 判据：
   - 有 CC 链接且为 **`by/4.0`** → **可发布**
   - 有 CC 链接但是 **`by-nc-*` / `by-nd` / `by-sa`** → **不可**按 CC-BY 发布
   - **无任何 CC 链接** → 落到 arXiv 默认 `nonexclusive-distrib/1.0` → **不可再分发**
   - 期刊类：以 PDF 里的 "Open Access ... Creative Commons Attribution 4.0" 原文为准
     （注意 **Nature 也有开放获取的篇目**，别按刊名一刀切）

## 四、更广的原则

- **CC-BY** → 可再分发，需署名 + 注明是否修改
- **CC-BY-NC / CC-BY-ND / 版权保留** → 内部研究可用，**不要再分发**
- **arXiv** → 看 abs 页的 license 链接，不看刊名、不看 PDF 内文

`assets/ir/` 下的 IR 标准答案（YAML）是**本项目的原创工作**，由分析示例图后独立撰写，
不含原图内容，采用 MIT 许可。

自己从 PDF 建库：

```bash
python3 scripts/extract_figures.py 你的论文.pdf -o refs/
```
