# Schematic library notices

Only `CC0-1.0` and `CC-BY-4.0` figures may be copied to
`redistributable/`. Every copied figure must retain:

- authors or collaboration;
- article title and publication;
- DOI or arXiv identifier;
- license name and URL;
- a note describing extraction, crop, or resizing;
- SHA-256 of the distributed file.

Metadata-only records do not include the copyrighted image. Access must go
through the publisher, library subscription, or the author's lawful repository.

OpenAlex `license` and `oa_url` fields are discovery hints, not a redistribution
grant. Figure-level reuse requires checking the article's licence statement.
Crossref supplies bibliographic discovery only; a DOI record is not permission
to redistribute the figure. The PMC Open Access bucket is used only after the
version metadata reports an open, non-retracted CC BY licence.

The existing `assets/t3-exemplars/NOTICE.md` remains the authoritative
attribution file for the 17 legacy images.
